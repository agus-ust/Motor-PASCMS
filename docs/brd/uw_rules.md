### A.9 Sample underwriting rules

Build all nine; each is a row in one rules table.

| ID  | Class              | Condition                            | Outcome                              |
|-----|--------------------|--------------------------------------|--------------------------------------|
| R1  | Private car        | IDV above 2,500,000                  | Refer to underwriter                 |
| R2  | Any                | Vehicle age over 15 years            | Refer to underwriter                 |
| R3  | Any                | 3 or more claims in the last 3 years | Refer to underwriter                 |
| R4  | Any                | Break-in of more than 90 days        | Pre-inspection required before cover |
| R5  | Goods-carrying     | Hazardous goods carried              | Refer to underwriter                 |
| R6  | Fleet              | Fleet loss ratio over 110%           | Refer to senior underwriter          |
| R7  | Passenger-carrying | School bus, or more than 18 seats    | Refer to underwriter                 |
| R8  | Miscellaneous      | IDV above 4,000,000                  | Refer to underwriter                 |
| R9  | Any                | KYC not complete                     | Hold issuance                        |
